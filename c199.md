## Car 4 closed: three real defects, and the rest dispositioned with the code that decides them

**Merged:** #299 (squash `737a0fd`). 42 suspects — 11 error-discipline and 31 URL/sink — read against the current tree. Three were real and are fixed with tests that fail on the unfixed tree; the rest are already guarded, unreachable because the caller clamps, obsolete, or calls whose URL cannot be attacker-shaped.

### The three real ones

**The staging gates could not report a failed spawn — only crash.** `scripts/smoke-local.mjs` and `scripts/check-privacy-browser.mjs` ran children through `new Promise(ok => child.on("exit", …))`. `spawn` does not emit `exit` when the executable is missing or the cwd does not exist; it emits `error`, and an EventEmitter `error` with no listener is a thrown exception. The gate therefore died with a raw spawn trace *before* its `finally` closed the static server and removed `_pages_smoke/` / `_pages_privacy/`, which is exactly the residue that makes the next run untrustworthy — and the operator saw a Node stack instead of `SMOKE FAIL …`. `scripts/lib/run-child.mjs` resolves a non-zero code on that path (and on a synchronous spawn throw); both gates share it.

**`laborMidPerKwh(null)` threw inside the cost model.** A default parameter only covers `undefined`, so `laborPerKwh: null` reached `null[0]` and threw. An unusable range is now a missing range and the installed default applies.

**`paretoFront(undefined)` / `paretoFront([null])` threw**, and an unpriced point sorted among priced ones. A non-array is now `[]`, and a point needs a finite cost *and* a finite outcome to be placed. An unknown price is not a cheap price.

Tests: a missing executable resolves 1; a real child returns its own status; a signalled child never counts green; `null`/`{}`/NaN/`undefined` ranges fall back while real ranges still win; `paretoFront` drops null and unpriced points and keeps the true frontier.

### Scope B — the 31 URL/sink items

One class, disposed together after spot-reading the ones that could matter: every item is a `fetch`, `navigate`, `appendChild` or URL builder whose input is a **constant**, a **number validated upstream**, or a **base URL already constrained** by `normalizeBase` (`tests/script-hardening.test.mjs` pins every form it accepts) and the origin gate (`apiTarget`, `aimsOutsideSite`, `resolveHref` all have tests there). The three highest-confidence entries — `setInputs` (0.99), `capture` (0.92), `runLifecycleFlow` (0.88) — are Playwright/CDP actions against the local staged origin, not sinks that can be pointed elsewhere. No item in this class can construct a URL from attacker-controlled text.
