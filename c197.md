## Car 2: three real defects, 24 of 51 dispositioned, and 27 that cannot be identified

**Merged:** #300 (squash `a40d589`). Suite **1,899/1,899** (up 9); stamp `20261023h → 20261023j`, `sw.js` `beco-v147 → beco-v149`.

Every item here is at prescription confidence 0.04–0.86, so each is a suspect and the code decides. Three were real, and all three share one shape: **a boundary that accepted whatever arrived.**

- **`callGroq` / `worker/index.js`** — the three call sites all guard the fetch with `.catch(() => null)` because a transport throw would escape `handleChat` as a Worker exception (500, no CORS, chat stuck on "Thinking…"). `await groqRes.json()` was the second way upstream can throw and had no guard. Fixed; the degraded reply keeps any text already streamed.
- **`setCoords` → `cities.js`** — `Number("")` is 0 and 0,0 is a valid coordinate, so a blank lat in a partition row or a geocoder reply became a plausible place in the Gulf of Guinea. The prescribed *crash* does not occur — `renderSunPath` clamps, `estimateTariff` falls back, `run()` refuses — so the fix is one layer down at the source.
- **`runPrivacyFlow`** — the coordinate-precision finding compared a coordinate's **magnitude** with 1 (`0.01 * 100`), not its decimal places with the two the product ships. It flagged every correctly rounded request outside ±1° and was blind to `latitude=0.512345` in Nairobi; its regex also matched `lat` only, so a four-decimal longitude beside a clean latitude was never examined.
