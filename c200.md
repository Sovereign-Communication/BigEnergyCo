### The one real defect: `createMapProviderRegistry`

```js
      if (!provider) return null;
      active = provider;                    // installed here
      return provider.init(options);        // init can reject
```

A blocked leaflet CDN is the concrete case — it is *why* the map is optional. With `active` set before the await, a rejected init left the provider installed: `onClick`, `drawRectangle` and `drawPolygon` reached a map that was never created, and `drawRectangle` returned the provider's result as though the map existed. `active = provider` now happens after the await resolves.

The single shipped caller (the roof-area map in `ui.js`) calls `cleanup()` in its `catch`, so no visitor-visible behaviour changes — which is why this is recorded as a contract violation rather than a shipped bug. The invariant belongs to the registry; the next caller should not have to rediscover the compensation. Failing-first proof: on the unfixed tree `drawRectangle` returns `{ok:true}` after a rejected init; on the fixed tree it returns `null` and the provider sees no call but its own `init`.
